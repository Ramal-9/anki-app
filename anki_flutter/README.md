# Anki Flow

Карточки для запоминания слов в стиле Anki на **Flutter Web**: интервальные повторения (SM-2), тёмный интерфейс, **AI Practice** для тренировки произношения и **подсказки устойчивых фраз** при добавлении нового слова.

## Возможности

| Экран | Что есть |
|---|---|
| **Queue** | Градиентная карточка «In your queue» (сколько карточек готово, ~минут, new/review, прогресс дневной цели), кнопка *Study cards*, колоды, очередь с сортировкой (Due Date / Deck / Recently Added) |
| **Library** | Decks / Folders (умные папки: все, на сегодня, новые, трудные, за неделю), счётчики new/learning/review, создание колоды, кнопка ✨ **Generate Cards** |
| **Generate Cards** | Карточки из вставленного текста, фото (распознавание текста), файла (.txt/.md/.csv/.srt) или диктовки. Работает без интернета |
| **Колода** | Статистика, список карточек со статусом и сроком («in 2 weeks»), меню: Add Card, Import, Review, Quiz, Settings; кнопка *Study N cards* |
| **Изучение** | Quit, «0 of 29», кнопки ✏️ (редактировать карточку) и настроек, вопрос → *Show answer* 👀 → ответ, кнопки 2×2 again / hard / good / easy с интервалами, ᴀA, озвучка, AI Practice. Горячие клавиши: Space, 1–4 |
| **New Card** | Front (язык) / Back, картинка по URL, диктовка голосом, ✨ подсказки фраз, AI Practice, 👀 «создать обратную карточку» |
| **Insights** | Retention trend (7D/30D/90D/All, цель 90 %, линия 70 %), тепловая карта активности, прогноз повторений, итоги |
| **Account** | Email, **Sync** (Mac ⇄ iPhone, шифрование), **Spaced repetition** (пресеты Default / Aggressive / Relaxed / Custom), **Daily goals** (новые + повторения), **Notifications** (напоминание + календарь), **Voice** (UK / US / AU, выбор голоса), тема, экран |

### AI Practice (проверка произношения)
1. Слово или предложение читает «носитель» — голос браузера (Web Speech API, `speechSynthesis`), акцент UK / US / AU, режим 🐢 медленно.
2. Нажимаете микрофон и повторяете.
3. Браузер распознаёт речь (`SpeechRecognition`), приложение выравнивает услышанное с эталоном по словам (взвешенное расстояние Левенштейна) и ставит оценку 0–100. Слова подсвечиваются: зелёный — верно, оранжевый — близко, красный — неверно/пропущено. Нажмите на слово, чтобы послушать его отдельно.

Работает в **Chrome, Edge, Safari (iOS 14.5+)**. Firefox не умеет распознавать речь. Нужен HTTPS (GitHub Pages подходит) и разрешение на микрофон.

### Подсказки устойчивых фраз
При вводе слова на лицевой стороне карточки появляется блок **Useful phrases & collocations**:
- встроенный офлайн-словарь (~120 слов, 4–8 частых сочетаний с переводом на русский) — `lib/data/collocations.dart`, легко расширять;
- если в словаре мало вариантов, подтягиваются частые сочетания из бесплатного API [Datamuse](https://www.datamuse.com/api/) (без ключа; отключается в Account → Online phrase suggestions);
- нажатие на фразу добавляет её в ответ как пример, ➕ создаёт отдельную карточку.

Чтобы подключить другой источник (например, LLM), реализуйте `OnlineSuggestionProvider` в `lib/services/suggestions.dart`.

### Без интернета (офлайн)
После первого открытия приложение целиком сохраняется в браузере (service worker `web/sw.js`), и дальше открывается и работает **без интернета**: колоды, изучение, статистика, Generate Cards, озвучка голосами устройства. Без сети не работают только: распознавание речи в AI Practice (Safari/Chrome отправляют звук на свои серверы), онлайн-подсказки Datamuse, перевод слов в Generate Cards, распознавание текста на фото при первом использовании и синхронизация (она догонит, когда сеть вернётся).

На iPhone лучше установить как приложение: Safari → «Поделиться» → **На экран «Домой»**. На Mac: Safari → Файл → **Добавить в Dock** (или Chrome → «Установить приложение»).

После `flutter build web` нужно запустить `python3 tool/offline.py build/web` (workflow делает это сам): скрипт записывает в `sw.js` список файлов и номер сборки, чтобы обновления подхватывались.

### Синхронизация Mac ⇄ iPhone (безопасная)
Account → **Sync**. Данные шифруются **на устройстве** (AES-256-GCM, ключ из вашего пароля синхронизации через PBKDF2-SHA256, 210 000 итераций) и хранятся в **секретном gist вашего GitHub-аккаунта** в виде нечитаемого шифротекста. Своего сервера нет, пароль никуда не отправляется.
1. На первом устройстве: создайте токен GitHub только с правом `gist` (Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → галочка **gist**), вставьте его и придумайте пароль синхронизации.
2. Там же нажмите **Copy setup code** и перешлите код себе на второе устройство (AirDrop, Заметки).
3. На втором устройстве: Sync → **I have a setup code** → вставьте код и тот же пароль.

Изменения с обоих устройств объединяются (ничего не затирается, удаления учитываются), синхронизация идёт автоматически после изменений, каждые 2 минуты и при возврате в приложение.

### Голоса носителей (UK / US)
Account → **Voice**: акцент, скорость и выбор голоса с прослушиванием. Приложение само выбирает самый естественный голос устройства и **не использует роботизированные** (Eloquence: Eddy, Flo, Reed..., а также Fred, Zarvox, Albert и т. п.). Лучше всего звучат бесплатные голоса Apple Premium/Enhanced, их нужно один раз скачать:
- **iPhone**: Настройки → Универсальный доступ → Устная речь → Голоса → Английский → UK: *Serena (Premium)* или *Daniel (Enhanced)*; US: *Ava (Premium)*, *Zoe (Premium)* или *Evan (Enhanced)*.
- **Mac**: Системные настройки → Универсальный доступ → Устный контент → Системный голос → Управлять голосами… → English (United Kingdom / United States).

После загрузки перезапустите браузер/приложение и выберите голос в Account → Voice.

### Уведомления
Account → **Notifications**: включение и время напоминания. Веб-приложение может показать уведомление, пока оно открыто или свёрнуто (на iPhone только если установлено на экран «Домой», iOS 16.4+). Для надёжного ежедневного напоминания нажмите **Add daily reminder to Calendar**: событие с будильником добавится в Календарь iPhone/Mac.

### Экран: iPhone и Mac
Приложение само определяет устройство и размер окна:
- **iPhone** (например, iPhone 13, 390×844) и узкие окна: раскладка телефона с нижней панелью;
- **Mac** и окна шире 900 pt: боковое меню слева, колоды в несколько колонок, Insights в две колонки.

В **Account → Screen & layout** видно, какое устройство определено, и можно вручную выбрать раскладку (Auto / Phone / Desktop), масштаб интерфейса (70–140 %), размер текста, ширину колонки телефона, а также пресеты «iPhone 13», «Mac», «Large text».

## Запуск локально

```bash
flutter pub get
flutter run -d chrome
```

Тесты логики (SM-2, оценка произношения, подсказки):

```bash
flutter test
```

Все данные хранятся в `localStorage` браузера (и, если включена синхронизация, в зашифрованном виде в вашем gist). При первом запуске загружаются демо-колоды *English* и *Olympiad* с историей повторений; сбросить или стереть их можно в Account → ··· .

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него эту папку:
   ```bash
   git init
   git add .
   git commit -m "Anki Flow"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` сам соберёт приложение и опубликует его по адресу
   `https://<ваш-логин>.github.io/<репозиторий>/` после каждого push в `main` (вкладка **Actions** показывает ход сборки).

Собрать вручную:

```bash
flutter build web --release --no-web-resources-cdn --base-href /<репозиторий>/
python3 tool/offline.py build/web
# содержимое build/web можно выложить на любой статический хостинг
```

## Структура

```
lib/
  main.dart                    приложение, нижняя навигация
  theme.dart                   цвета, градиенты, название (AppConfig.appName)
  display.dart                 определение устройства, раскладка, масштаб
  models.dart, srs.dart        модель карточек и планировщик SM-2
  store.dart                   состояние + сохранение в localStorage, демо-данные
  data/collocations.dart       офлайн-словарь фраз
  services/speech.dart         Web Speech API (озвучка и распознавание)
  services/pronunciation.dart  оценка произношения
  services/suggestions.dart    подсказки фраз (офлайн + Datamuse)
  services/card_generator.dart генерация карточек из текста (офлайн)
  services/sync*.dart          синхронизация: шифрование, gist, слияние
  services/notify.dart         уведомления и напоминание в календарь
  screens/                     queue, library, deck, study (+quiz), card_editor, ai_practice, insights, profile,
                               search, settings_pages, voice_settings, sync_screen, generate_cards
web/sw.js                      офлайн-кэш (service worker)
tool/offline.py                вписывает список файлов в sw.js после сборки
test/                          тесты логики, слияния, генератора, шифрования
```

Название и автор меняются в `lib/theme.dart` (`AppConfig`).
